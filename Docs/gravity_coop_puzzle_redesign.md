# 중력 협동 퍼즐 상세 설계안

상태: 이 설계를 바탕으로 Primitive 블록아웃을 구현했다. 실제 배치와 참고 풀이는 `gravity_coop_prototype_guide.md`, 검증 결과는 `gravity_coop_validation.md`를 참조한다. 두 사람의 재미 평가는 별도 플레이 테스트가 필요하다.

기준: `gravity_coop_implementation_spec.md` 우선, `gravity_coop_game_idea.md`의 비대칭 협동 의도 유지. 기존 5개 퍼즐의 학습 순서와 4방향 전체 중력 규칙을 유지한다.

## 1. 이번 설계에서 검증할 재미

**조작자는 여러 물체의 다음 상태를 계획하고, 내부 플레이어는 그 계획을 실행할 수 있는 공간 상태를 만든다.**

반복 흐름:

1. 조작자가 플레이어와 상자의 서로 다른 낙하 경로를 발견한다.
2. 둘이 당장 이동할 대상과 잠시 보관할 대상을 정한다.
3. 내부 플레이어가 상자 위치, 레버, 자신의 출발 위치를 조정한다.
4. 내부 플레이어가 준비됐음을 알리면 조작자가 중력을 바꾼다.
5. 둘이 실제 결과를 보고 다음 행동을 수정한다.

상자의 흔들림이나 조금 다른 착지는 허용한다. 정확한 좌표나 정해진 방향 문자열을 맞혀야 하는 퍼즐로 만들지 않는다.

## 2. 사용할 기믹의 실제 규칙

### A. 두 방향에서 유지되는 상자 보관 홈

- 고정 벽 두 면으로 만든 모서리 또는 짧은 막다른 통로다. 자석이나 중력 면역은 없다.
- 예를 들어 천장과 오른쪽 턱이 만나는 홈은 위쪽 중력에서 천장이, 오른쪽 중력에서 턱이 상자를 받친다.
- 압력판 판정은 상자가 두 접촉 위치 사이에서 조금 움직여도 유지될 만큼 넓게 배치한다. 한 점을 맞히게 하지 않는다.
- 홈의 열린 쪽으로 중력을 바꾸면 상자가 나온다. 영구적으로 해결 상태를 고정하지 않는다.
- 내부 플레이어가 운반하여 홈의 입구와 같은 낙하 선에 상자를 놓아야 한다.
- 조작자는 다음 이동에 쓸 방향에서도 상자가 유지될 홈인지 판단한다.

의도하는 대화: “위로 보내면 저 홈에 들어가. 그다음 오른쪽으로 바꿔도 상자는 남아 있을 거야.”

### B. 레버로 선택하는 두 갈래 낙하 통로

- 한 레버에 두 개의 고정 문을 연결한다. 레버 상태에 따라 A 통로가 열리고 B가 닫히거나 그 반대가 된다.
- 중력은 상자를 움직이고 레버는 통과 가능한 길만 바꾼다. 상자를 순간이동시키지 않는다.
- 레버를 조작할 수 있는 위치와 분기 끝의 목적지는 떨어져 있다. 내부 시점에서 두 목적지를 동시에 보기 어렵게 배치한다.
- 조작자는 현재 중력과 상자 위치를 보고 어느 통로를 열지 제안한다. 내부 플레이어는 상자가 문을 다 지나갔는지, 자신이 다음 장치로 갈 수 있는지 확인한다.
- 상자나 플레이어가 닫힐 문 공간에 있으면 전환을 보류하고 가까운 장치에 막힘 상태를 표시한다. 물체 안에 문을 생성해서 밀어내거나 압착하지 않는다.
- 레버는 중력 조작자의 원격 버튼으로 대신 작동할 수 없다.

의도하는 대화: “지금 A를 열면 상자가 아래 회수 통로로 가. 먼저 위쪽 받침에 올리고 B로 보내자.”

### C. 플레이어와 상자의 안전한 방향이 다른 상황

- 플레이어가 가려는 출구 방향으로 바로 중력을 바꾸면, 아직 보관하지 않은 상자가 압력판을 떠나거나 잘못된 통로로 들어간다.
- 해결 방법은 내부 플레이어가 상자를 보관 홈에 넣거나, 레버로 상자의 길을 바꾸고 자신은 다른 이동선으로 빠지는 것이다.
- 초반에는 잘못된 선택이 상자 회수로 이어진다. 위험 요소와 결합하는 것은 후반 한 구간으로 제한한다.
- 단순 대기 대신 내부 플레이어가 수행할 준비 행동이 있어야 한다.

### D. 점프와 중력 전환으로 고정 발판 환승

- 이동식 발판 시스템을 추가하지 않는다. 출발 발판, 넓은 중간 발판, 도착 발판을 사용한다.
- 내부 플레이어가 발판의 턱을 점프로 벗어난 뒤, 조작자가 다른 방향의 중력으로 착지 경로를 만든다.
- 내부 플레이어는 공중 조작으로 발판의 깊이와 좌우 위치를 보정한다.
- 실패 지점 아래에는 회수용 바닥을 둔다. 첫 시도부터 사망을 요구하지 않는다.
- 중간 발판에 멈춰 다음 이동을 논의할 수 있다. 연속 반사 신경 시험으로 만들지 않는다.

## 3. 5개 퍼즐

아래 도식은 연결 관계다. 실제 길이·높이·깊이와 물리적 통과 가능성을 확정한 도면은 아니다. 구현 단계에서 Primitive 배치로 경로와 우회를 먼저 검증한다.

| 퍼즐 | 주요 학습 | 조작자가 푸는 문제 | 내부 플레이어가 푸는 문제 | 목표 첫 풀이 시간 |
|---|---|---|---|---|
| 1. 벽으로 건너가기 | 출발 위치에 따른 낙하 경로 | 어디에서 바꾸면 다음 받침에 닿는가 | 어느 통로로 출발 위치에 갈 것인가 | 1–2분 |
| 2. 상자 주차 | 중력이 바뀌어도 준비한 상태 유지 | 다음 방향에서도 상자가 남는가 | 상자를 어디에 놓고 자신은 어디로 빠질 것인가 | 2–3분 |
| 3. 두 갈래 배송 | 통로 선택과 중력 순서 | 어느 경로와 순서로 상자를 보낼 것인가 | 언제 레버를 바꾸고 상자를 다시 배치할 것인가 | 3–4분 |
| 4. 공중 환승 | 전환 시점과 공중 조작 | 언제 방향을 바꾸면 넓은 발판에 떨어지는가 | 어디서 점프하고 어떻게 착지를 보정할 것인가 | 2–3분 |
| 5. 두 상자와 탈출로 | 보관·분기·환승 결합 | 두 상자가 동시에 어떻게 움직일 것인가 | 먼저 준비할 대상과 이동 순서를 어떻게 정할 것인가 | 4–6분 |

시간은 난이도 조절 목표이며 측정 결과가 아니다.

### 퍼즐 1 — 벽으로 건너가기

구성: 캐릭터, 계단형 고정 벽, 출발 받침 두 곳, 넓은 벽 쪽 착지 받침, 출구. 상자·장치·위험 요소는 없다.

```text
출발 바닥 → 내부 통로 → 출발 받침
                          │ 중력 변경
                          ↓
                      벽 쪽 받침 → 표면 이동 → 출구
```

- 두 출발 받침은 겉으로 비슷하지만, 하나는 다음 표면으로 이어지고 다른 하나는 고정 턱에 가로막힌다.
- 조작자는 방 전체에서 연결을 확인한다. 내부 플레이어는 주변 통로를 따라 선택한 받침으로 간다.
- 잘못된 위치에서 바꾸면 안전한 벽에 착지한다. 둘이 위치를 다시 맞추면 회복할 수 있다.
- 출구에 도착하기 위한 이동 자체에 전후 깊이 선택을 포함한다. 마지막 W 입력 한 번만으로 역할 참여를 체크하는 구조는 피한다.

내부 플레이어의 재미: 자신의 출발 위치가 떨어지는 결과를 바꾼다는 감각.

조작자의 재미: 현재 화면에서 멀리 떨어진 두 표면이 새 중력에서 연결된다는 발견.

검증 조건: 내부 플레이어를 정지시킨 채 중력만 반복해도 출구까지 운반할 수 있다면 받침과 깊이 배치를 수정한다. 반대로 일반 점프만으로 전 구간을 건너도 수정한다.

### 퍼즐 2 — 상자 주차

구성: 상자 1개, 천장 모서리 보관 홈, 홈 안 압력판, 출구 문, 사람용 우회 통로. 위험 구역은 없다.

```text
상자 준비 자리 ── 위쪽 낙하 ─→ [천장 압력판 + 오른쪽 받침 턱]
       │                         ↑ 위/오른쪽에서 유지
       └→ 사람용 우회 자리 ── 오른쪽 낙하 ─→ 출구 문
```

기준 풀이:

1. 조작자가 압력판 아래의 낙하 선과 받침 턱을 발견한다.
2. 내부 플레이어가 상자를 그 선에 운반하고 내려놓는다.
3. 위쪽 중력으로 상자와 플레이어를 보낸다.
4. 내부 플레이어가 상자를 밀어내지 않도록 옆 깊이 통로로 빠지고 다음 이동 위치를 고른다.
5. 조작자가 오른쪽 중력으로 바꾼다. 상자는 턱에 받쳐 압력판을 유지하고, 플레이어는 출구 쪽으로 이동한다.

상자를 평평한 천장에만 올려놓으면 오른쪽 전환에서 미끄러져 압력판이 풀린다. “상자를 올렸는가”에 더해 “다음 중력에서도 남는가”를 생각하게 한다.

상자가 빠지면 바닥에서 회수할 수 있다. 문은 압력판이 풀리면 닫히므로 출구 조건을 영구 저장하지 않는다.

검증 조건: 홈의 유지가 높은 마찰값이나 정확한 좌표에 의존하면 홈 크기와 받침을 수정한다. 플레이어가 상자를 든 채 출구에 도착하는 방법으로 압력판을 대체할 수 없어야 한다.

### 퍼즐 3 — 두 갈래 배송

구성: 상자 1개, 중간 보관 받침, 분기 레버, 상반되게 열리는 문 2개, 압력판 목적지, 회수 통로, 출구.

```text
준비 자리 → A 입구 문 → 분기실 / 중간 받침 → B 배송 문 → 목적지 압력판
                        │
                        └→ 잘못된 낙하 → 회수 통로 → 준비 자리

레버 OFF: A 열림 / B 닫힘     레버 ON: A 닫힘 / B 열림
```

기준 풀이:

1. 조작자는 상자의 현 위치에서 바로 B 방향으로 떨어뜨리면 고정 턱에 막힌다는 것을 확인한다.
2. 내부 플레이어가 운반 위치를 조정하고 A 쪽 접근 통로를 연다.
3. 둘이 중력을 바꾸어 상자를 분기 전 중간 받침으로 보낸다.
4. 상자가 문 구간을 벗어난 것을 확인한 뒤 내부 플레이어가 B로 바꾸고 안전한 자리로 이동한다.
5. 조작자가 다음 중력으로 상자를 목적지에 보낸다. 내부 플레이어는 열린 출구로 간다.

A는 분기실에 상자를 넣는 길, B는 다른 방향으로 내보내는 길이다. 분기실은 두 길이 만나는 T자 구조로 배치한다. 처음부터 B를 열면 A가 닫혀 상자를 분기실에 넣을 수 없고, A를 계속 열어두면 B가 닫혀 배송할 수 없다. 회수 통로는 잘못된 중력에서 접근 가능한 낮은 자리로 상자를 되돌리는 고정 경사·받침 구조다.

잘못된 순서에서는 상자가 회수 통로로 돌아오거나 받침에 막힌다. 초기화를 누르지 않고도 상태를 읽고 다시 시도할 수 있게 한다.

내부 플레이어는 레버 앞에서 기다리기만 하지 않는다. 상자 준비 위치와 레버 접근 통로가 분리되어 있어, 그 사이 이동과 재배치가 풀이에 들어간다.

검증 조건: 레버를 처음부터 B로 고정한 채 중력만 바꿔도 성공하면 분기 구조를 수정한다. 상자를 통째로 들고 최종 목적지까지 걸어갈 수 있는 지름길도 확인한다.

### 퍼즐 4 — 공중 환승

구성: 출발 발판, 낮은 출발 턱, 넓은 중간 발판, 도착 발판, 안전한 회수 바닥. 필요하면 마지막 통과 구간에 고정 위험 요소 1개를 둔다.

```text
출발 발판 ─ 점프·중력 전환 ─→ 넓은 중간 발판
                                      │ 정지하고 다음 이동 논의
                                      └─ 점프·중력 전환 ─→ 도착 발판
          [놓치면 돌아갈 수 있는 회수 바닥]
```

- 출발 턱에 붙어 서 있는 동안 바꾸면 캐릭터가 턱에 걸린다. 내부 플레이어가 점프해 턱을 벗어난 것을 보고 방향을 바꿔야 한다.
- 출발선은 하나의 정답 점이 아닌 넓은 영역이다. 점프 위치에 따라 조작자가 전환 시점을 조금 달리 잡는다.
- 도착 발판의 깊이는 출발 위치와 다르게 두어 내부 플레이어의 공중 보정이 의미를 갖게 한다.
- 중간 발판은 넓고 위험하지 않다. 첫 환승 성공 후 대화할 시간을 준다.
- 현재 주기 레이저가 꺼질 때까지 기다리는 것을 주된 풀이로 사용하지 않는다. 타이밍의 기준은 상대 플레이어의 실제 움직임이다.

초기 목표: 유효 전환 구간 0.8초 이상, 착지 발판 폭 3 캐릭터 지름 이상. 실제 수치는 아래 물리 제약과 함께 조정한다.

검증 조건: 정지 상태의 플레이어를 중력만으로 끝까지 보낼 수 있는지, 한 방향 중력과 점프만으로 전부 건너는지 각각 확인한다. 실패 원인이 보이지 않는 판정이나 지연이면 구간을 넓힌다.

### 퍼즐 5 — 두 상자와 탈출로

구성: 동일한 물리 규칙의 상자 2개, 압력판 보관 홈 2곳, 분기 레버와 통로 문, 넓은 환승 발판, 출구. 상자 A/B 표시는 의사소통용이며 전용 열쇠 속성이 아니다.

```text
상자 A 준비 → 홈 A / 압력판 A ──────┐
                                   ├→ 두 압력판 유지 → 출구 문
상자 B 준비 → 분기 통로 → 홈 B ────┘
                   ↑
              내부 플레이어 레버
                   │
              안전 발판 → 환승 → 출구
```

세 번의 협의가 생기도록 구성한다.

**첫 협의 — 무엇을 먼저 보관할까?**

조작자는 상자 B를 바로 보내면 상자 A가 압력판 후보 위치에서 밀려난다는 것을 발견한다. 내부 플레이어는 A를 홈 A의 낙하 선에 준비한다. 홈 A는 B를 배송할 두 방향의 중력을 견디게 배치한다.

**두 번째 협의 — 남은 상자를 어느 길로 보낼까?**

내부 플레이어가 B의 위치를 조정하고 레버로 배송 통로를 연다. 조작자는 A의 유지 상태와 B의 이동을 함께 본다. 먼저 해결한 A가 빠지면 원인을 이야기하고 회수한다.

**세 번째 협의 — 물체를 유지하면서 어떻게 탈출할까?**

두 홈이 유지되는 방향 안에서, 내부 플레이어가 안전 발판으로 가서 점프하고 조작자가 전환 시점을 맞춘다. 두 압력판을 실제로 누르는 동안 출구에 도착하면 성공한다.

이 방에서는 보관 홈 A, B, 분기 끝, 출발 발판이 내부 카메라 한 화면에 동시에 들어오지 않아야 한다. 조작자는 전체를 보고, 내부 플레이어는 가까운 상자와 레버의 실행 가능성을 보고 판단한다.

처음에는 회수 가능한 실패를 우선한다. 위험 요소를 넣는다면 한 곳에만 배치하고, 상자 접촉만으로 무조건 방 전체를 재시작하는 기존 판정은 이 배치에서 다시 검토한다. 반복 운반 시간이 재미를 잡아먹으면 위험 요소를 줄인다.

검증 조건: A/B 중 어느 상자를 먼저 쓰는 다른 풀이도 허용한다. 정해진 순서를 체크하는 숨은 조건은 없다. 실제로 두 압력판이 유지되고 플레이어가 출구에 오면 성공이다.

## 4. 두 역할이 공간을 읽을 수 있게 하는 최소 표시

- A/B 통로, 보관 홈, 압력판에 같은 문자·간단한 형태 표식을 반복해서 연결 관계를 알린다. 색만으로 구별하지 않는다.
- 조작자는 전체 배치, 현재 중력, 압력판과 통로 상태를 본다. 정답 방향이나 자동 낙하 예측선은 표시하지 않는다.
- 내부 플레이어는 가까운 레버에서 E 조작 안내, 선택된 통로, 전환이 막힌 이유를 확인한다. 먼 장치의 전체 상태 목록은 보여주지 않는다.
- 보관 홈의 앞/뒤 깊이가 중요한 경우 조작자의 고정 시점에 작은 기울기를 주어 턱과 깊이를 읽을 수 있게 한다. 중력 변경으로 관찰 화면이 회전하지 않는 규칙은 유지한다.
- 제한된 3인칭 시야를 유지하되, 몸에 가까운 벽이 카메라를 가려 실패 이유를 숨기지 않는지 확인한다.

## 5. 현재 물리 값으로 지킬 배치 제약

현재 기본 중력 가속도는 18, 점프 초기 속도는 7이다. 수직 점프의 이론상 최고 높이는 약 1.36유닛이고 원래 높이까지 돌아오는 시간은 약 0.78초다. 콜라이더와 바닥 상태에 따라 실제 통과 가능 범위는 더 작을 수 있다.

- 2유닛 이상의 턱을 일반 점프로 넘는 풀이를 가정하지 않는다.
- 점프만 한 채 오래 기다리는 타이밍을 요구하지 않는다. 중력 변경 후 낙하 경로와 넓은 발판으로 성공 구간을 확보한다.
- 중력 변경 대기시간 0.5초를 유지하고, 그보다 빠른 연속 전환을 정답에 넣지 않는다.
- 크기 1 상자가 지나가는 통로에는 초기 폭 1.6유닛 이상을 주고, 모서리와 회전에서 걸리는지 확인한다.
- 보관 유지 여부는 실제 Rigidbody로 검사한다. 상자를 kinematic으로 고정하거나 속도를 임의로 없애서 성공시키지 않는다.
- 압력판의 넓이는 받침 안에서 상자가 정착할 수 있는 영역을 덮되, 옆 통로에 있는 상자가 잘못 누르지 않게 한다.

## 6. 구현 변경 범위

| 위치 | 변경 |
|---|---|
| `GravityPrototypeBuilder` | 5개 방의 고정 발판·통로·보관 홈·분기 문 배치 |
| `GravityPuzzle` | 레버가 제어하는 통로 문 연결, 출구 레버 조건과 경로 레버 용도 구분 |
| 레버 상호작용 처리 | 닫힐 위치에 물체가 있으면 전환 보류. 서버 판정과 상태 동기화 |
| 역할별 UI / 카메라 | 가까운 상호작용 안내, A/B 표식, 깊이 가독성 확인 |
| 자동 플레이 테스트 | 새 경로의 완료 가능성과 정지 플레이어·고정 중력·고정 레버 우회 검사 |

기존 중력·이동·서버 물리·입력 RPC·연결 흐름은 재사용한다. 범용 장치 그래프, 새로운 능력, 부분 중력, 자석, 이동 발판 시스템은 이 설계에 필요하지 않다.

## 7. 구현 순서와 통과 기준

1. **퍼즐 2의 보관 홈만 먼저 회색 상자로 검증한다.** 위→오른쪽에서 압력판 유지, 반대 방향에서 회수, 내부 플레이어의 우회 이동을 확인한다.
2. **퍼즐 3의 분기만 검증한다.** 레버가 실제 경로를 바꾸고 순서에 따라 결과가 달라지는지 확인한다. 문이 물체를 끼워 넣지 않아야 한다.
3. **퍼즐 1과 4를 연결한다.** 이동·점프·전환의 성공 범위를 넓게 잡고 네 중력 방향에서 반복한다.
4. **검증된 구조로 퍼즐 5를 조합한다.** 단독 요소 검증 전에 종합 퍼즐부터 완성하지 않는다.
5. **두 프로세스에서 전체 플레이, 리셋, 장치 동기화를 검사한다.** 기존 검증 기록은 기존 배치의 결과이므로 새 설계의 통과 근거로 사용하지 않는다.
6. **두 사람이 역할을 바꿔 테스트한다.** 사람의 재미 평가는 자동 완료와 구분한다.

관찰할 질문:

- 조작자가 먼저 발견하고 제안한 경로나 위험이 있었는가?
- 내부 플레이어가 상자 위치·출발 위치·레버 시점을 스스로 선택했는가?
- “어느 방향?” 외에 “무엇을 먼저?”, “어디에 놓을까?”, “지금 준비됐어?”라는 대화가 생겼는가?
- 실패 후 둘이 원인을 설명하고 다른 시도를 할 수 있었는가?
- 한쪽이 15초 이상 할 일 없이 기다렸다면 상대의 어떤 준비 과정을 줄이거나 병행할 수 있는가?
- 역할별 재미를 각각 1–5로 물었을 때 한쪽만 반복적으로 낮게 평가하는가?

퍼즐마다 계획을 제안하는 순간과 직접 준비하는 순간이 한 번 이상 생기는 것을 초기 목표로 삼는다. 관찰 결과 한쪽이 지시를 수행하기만 한다면 장애물을 추가하기 전에 시야, 물체 배치, 장치 접근 순서를 먼저 수정한다.

## 블록아웃에서 구체화한 선택

- 퍼즐 5는 두 상자를 먼저 준비한 뒤 함께 위로 보내는 풀이도 허용한다. 준비한 상자를 이동 중 다시 밀지 않도록 깊이 통로로 우회하는 행동이 들어간다.
- 퍼즐 4는 주기 레이저 대기 대신 두 번의 점프·중력 전환과 넓은 착지면으로 구성했다. 정해진 점프 횟수를 체크하지 않는다.
- 퍼즐 3과 5의 레버를 입구 왼쪽에 배치하여 플레이어가 열린 입구에 빨려 들어가지 않고 배송 통로를 전환할 수 있도록 했다.
- 관찰 시점의 고정 높이 차와 문자 표식으로 앞/뒤 통로 및 P/Q 목적지를 구별한다.
